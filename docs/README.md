# Tested Configurations

This directory contains tested configurations that have been shared by users. These configurations are known to work with specific camera models and can serve as a starting point for similar setups.

## How to Use These Configurations

1. Find a configuration that matches your camera model
2. Copy the relevant parts to your Homebridge config
3. Adjust the IP addresses, usernames, and passwords to match your setup
4. Test the configuration and make adjustments as needed

## Contributing a Configuration

If you have a working configuration for a camera model not listed here, please:

1. Create a new issue using the [tested config template](https://github.com/homebridge-plugins/homebridge-camera-ffmpeg/issues/new?assignees=&labels=tested+config&template=tested_config.md)
2. Include the manufacturer/model information
3. Provide your complete working configuration (remove sensitive information)
4. Add any relevant additional information about your setup
